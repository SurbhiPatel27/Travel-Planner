# ✈️ Travel Planner

A simple and interactive travel planning website built using HTML, CSS, and JavaScript.

## 🌍 About the Project

Travel Planner helps users organize their trips by selecting a destination, entering their travel duration and budget, choosing a travel preference, and adding activities to their itinerary.

Users can also add the estimated cost of each activity and track the total activity expenses.

## ✨ Features

* Select a travel destination
* Enter trip duration
* Set a travel budget
* Choose a travel preference
* Add activities to the itinerary
* Add estimated activity costs
* Automatically calculate total activity cost
* Remove activities from the list
* Responsive design for different screen sizes

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.
4. Enter your trip details and start planning.
